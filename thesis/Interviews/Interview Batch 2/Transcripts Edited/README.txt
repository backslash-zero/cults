TRANSCRIPTS EDITED — README

This folder holds cleaned-up, dialogue-formatted versions of the 2 raw files in
../Transcripts-Raw, one edited file per interview:

- Aug 13 at 18-32.txt
- Aug 13 at 18-40.txt

Both raw files are complete, standalone interviews with different interviewees
(different ages, nationalities, and main languages) — neither is a two-take split
of the other, so no merging was needed.

WHAT WAS DONE TO EACH FILE
1. Speaker turns: the raw auto-transcripts have no diarization at all — interviewer
   and interviewee speech runs together in undifferentiated paragraphs. Both files
   here have been split into "Interviewer:" / "Interviewee:" turns by reading for
   who's asking vs. answering. This is a best-effort reconstruction, not a verified
   transcript — treat turn boundaries as likely-correct, not certain.
2. Light cleanup: filler words, false starts, and obvious repeated words were
   smoothed for readability without changing meaning. Recurring, unambiguous
   ASR errors for "cult" (e.g. "a cut," "chords") were corrected silently, matching
   the pattern already established in Interview Batch 1.
3. Likely mistakes: less certain corrections (misheard names, garbled phrases,
   ambiguous words) are flagged inline with [?] and explained in a
   "TRANSCRIPTION / EDITING NOTES" section at the bottom of each file, rather than
   silently changed. The most notable ones:
   - "the setup" → almost certainly "la setta," Italian for "cult"/"sect" (Aug 13,
     18:40 interview — the interviewee is giving the Italian translation of "cult")
   - "Mr. Mooney" → likely a reference to Sun Myung Moon, founder of the
     Unification Church ("the Moonies"), which the same interviewee names directly
     a few lines later (Aug 13, 18:32 interview)
4. Demographics: each file's header lists the interviewee's stated age, gender,
   main language, language spoken, country of residence, and nationality, exactly
   as captured in the raw transcript. Both interviews had all fields captured
   clearly in the raw text.

WHAT WASN'T DONE
- No audio was available to verify any of this — everything above is inferred from
  the raw text alone. Anywhere the notes flag uncertainty, treat it as worth
  double-checking against the original recordings if it matters for your thesis.
- Nothing was removed for content reasons; one masked profanity in the raw text
  ("S***") was left as-is.
