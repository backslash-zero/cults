\section{In short: what did this run find?}
\label{sec:short}
% ============================================================

For a reader who wants the gist before the detail. Every claim below is
unpacked, with numbers and caveats, later in this document.

\begin{itemize}[leftmargin=1.4em]
  \item \textbf{The corpus got much smaller, on purpose.} A manual
  fidelity check of the first extraction pipeline (v1) found it was
  pulling out paraphrases, mistranslations, and non-claims (headings,
  citations) as if they were genuine statements about cults. The
  pipeline was rebuilt around a strict "must be an exact quote"
  rule plus a second model that independently checks every candidate.
  The result: far fewer expressions survive (literature alone dropped
  from 39,236 to 5,741 -- an 85\% cut), but the ones that remain are
  verbatim and checked. This document is about that smaller, stricter
  dataset.
  \item \textbf{The three sources still barely form separate
  clusters} -- same conclusion as v1's run, at a similarly-near-zero
  silhouette score. Literature, the French government's MIVILUDES
  reports, and interview responses overlap substantially rather than
  occupying clearly separate regions of the space.
  \item \textbf{But something changed in how the three sources relate
  to each other.} In v1, the three corpora's average positions pointed
  in almost unrelated directions (cosine similarities near zero). In
  v2, literature, MIVILUDES, and interviews all point in a
  \emph{noticeably similar} direction (cosine similarities of
  0.52--0.64). One plausible reading, spelled out with its own caveats
  in Section~\ref{sec:interpretation}, is that stripping out noise
  (paraphrase drift, boilerplate, mislabelled non-claims) left a
  cleaner signal of what these three sources have in common when they
  talk about cults -- but a much smaller sample size can itself produce
  a tidier-looking average almost by chance, so this is not read as
  settled here.
  \item \textbf{Named things (people, specific groups) tend to sit at
  the edge of their own corpus's "typical" region; generic statements
  about cults/sects sit near the centre.} A new module run for the
  first time this session (Section~\ref{sec:typicality}) found this
  pattern in all three corpora.
  \item \textbf{One genuine, small data-quality finding}: a
  97-year-old interviewee's transcribed answer, "Sept?", is almost
  certainly a mishearing of the French word \emph{secte} (cult) as
  \emph{sept} (seven) -- not a substantive answer -- yet it passed every
  automated quality check. It is one point out of 10,646 in the whole
  space; not large enough to change any result, but worth being honest
  about (Section~\ref{sec:spotcheck}).
  \item \textbf{The interviews corpus is now so small (64 expressions)
  that no single named entity is mentioned by all three corpora at
  once} -- a real structural fact about this run's data, not a bug
  (Section~\ref{sec:entities}).
\end{itemize}

\section{Where the project stands}
\label{sec:stages}
% ============================================================

\subsection{Why a second pass at all}
A 100-item manual fidelity review of the first extraction pipeline
(2026-09-08) found it systematically over-inclusive: expressions that
paraphrased, mistranslated, or truncated their source; document
headings and bibliography citations pulled out as if they were claims;
occasional interviewer questions mislabelled as participant statements.
The pipeline (\jargon{v2}) was rebuilt around a strict verbatim-span
rule -- the extraction model may only return an exact substring of the
source text, checked by a deterministic code layer, not another model
call -- plus a Stage-1 text-integrity audit for broken PDF
character-encoding, deterministic (not model-guessed) interview
speaker-turn attribution, and a second, independently-prompted local
model that judges every retained candidate against the same criteria a
human reviewer would use. This "judge" model is described everywhere
in this document as \emph{model-judged}, never as a substitute for
human review. Full design rationale is in
\texttt{thesis/03\_Content/3\_Methods.tex}, section "Revising the
Extraction Pipeline"; v1's own archives, shared space, and every
retained run are left untouched on disk as a frozen historical
comparison point, not deleted or overwritten.

\subsection{Stage 1 -- The same three corpora, re-extracted}
The underlying source documents are the same three corpora as v1 (57
scholarly works, 2 MIVILUDES documents, 26 interview transcripts) --
nothing was added or removed at the document level. What changed is
how expressions were pulled out of them (previous subsection).

\subsection{Stage 2 -- A much smaller, stricter set of expressions}
Running the v2 pipeline end-to-end on all three corpora produced:

This is not a case of "different data" -- it is the same documents,
screened far more strictly. Section~\ref{sec:spotcheck} reports this
session's own quality check on a random sample of the v2 output.

\subsection{Stage 3 -- The same three reference vocabularies}
The three background word-lists (concept backbone, structural concepts,
ConceptNet-generalised concepts) are unchanged from v1 -- they were
built independently of either extraction pipeline and are reused as-is
(see the v1 document, Section 2, for how each was built).

\subsection{Stage 4 -- Far fewer emergent entities}
With a much smaller corpus, far fewer named things are mentioned often
enough to count as an \jargon{emergent entity}. v1 required at least 3
mentions and still found 3,251 entities; applying the same threshold to
v2 would have left only 1 entity, so the threshold was lowered to
\textbf{1 mention} for this run -- an explicit, logged design decision,
not a silent change. This produced \textbf{21} emergent entities (see
Section~\ref{sec:entities}).

\subsection{Stage 5 -- One shared geometric space, rebuilt}
The same pooling procedure as v1 (embed everything with the same
model, standardize, then PCA down to the smallest dimensionality that
keeps 95\% of the variance) was re-run on the v2 expressions plus the
17 MIVILUDES criteria and the three (unchanged) reference vocabularies.
This left \textbf{10,646} points, compressed to \textbf{389} dimensions
(95.0\% variance kept) -- a much smaller space than v1's 44,520 points
in 394 dimensions, but built the same way.

\subsection{Stage 6 -- The interview "first impression" layer: ported, not redone}
25 of the 26 interviews' manually-verified opening-prompt exemplars no
longer appear verbatim in v2's much stricter extraction (checked
directly). Rather than lowering standards to force them back in, the
existing, already-human-verified selections and their embeddings were
kept exactly as they were and simply projected through the new v2
coordinate system instead of v1's. This is the same "port, don't redo"
principle used elsewhere in this project: the embedding of a quote is a
property of its own words, not of which pipeline version happened to be
running when someone selected it.

\subsection{Stage 7 -- Rechecking whether the equal-$n$ correction still makes sense}
Because v2's corpus is so much smaller, it was worth explicitly
rechecking whether the same correction used throughout v1 for
literature's dominance still applies. It does: literature is
\textbf{97.09\%} of v2's expression points (versus 97.44\% in v1 --
essentially unchanged), so the same equal-size/equal-$n$ bootstrap
correction used throughout is still necessary and is used unchanged.
What does change is the absolute size of that equal-$n$ draw: v1 could
draw 204 points per source (matching the smallest, interviews); v2 can
only draw \textbf{64} (its own new smallest source). The correction
logic is identical; the numbers it produces this run rest on a smaller,
noisier sample, and confidence intervals reported below should be read
with that in mind.

\subsection{Stage 8 -- Running the toolkit against v2, and a spot-check}
The same reusable analysis toolkit used for v1 -- now parameterized to
point at either shared space via a single \texttt{--shared-space-dir}
flag rather than hardcoded v1 paths -- was rerun end-to-end against the
v2 space (run \texttt{20260909-224215}, covered by this document), plus
a tenth module, \texttt{analyze\_typicality}, run for the first time
this session (Section~\ref{sec:typicality}). One module,
\texttt{analyze\_emergent\_entities}, encountered a genuinely empty
result for its "entities mentioned by all three corpora" deliverable
(Section~\ref{sec:entities}) -- fixed to log and skip that one
deliverable explicitly rather than aborting the whole module, since an
empty result here is a real fact about this run's small corpus, not an
error to paper over. Separately, a fresh manual/automated spot-check
was run on the retained v2 output itself (Section~\ref{sec:spotcheck}).

\section{Key ideas, explained in plain language}
\label{sec:jargon}
% ============================================================

Unchanged from the v1 document -- included here again so this document
is self-contained. Skip if already familiar with embeddings and
dimensionality reduction.

\subsection{Embeddings and vector spaces}
An \jargon{embedding} is what you get when a piece of text is fed
through a trained language model and converted into a long list of
numbers -- a \jargon{vector} (1,024 numbers, here). Texts with similar
meaning end up as nearby lists of numbers: "a group led by a
controlling figure" and "an authoritarian leader dominates the members"
would land close together; the same phrase and "the recipe calls for
two eggs" would land far apart. A collection of such vectors is a
\jargon{vector space} or \jargon{embedding space}; because "nearby in
the numbers" tracks "similar in meaning," geometric ideas -- distance,
direction, clustering -- become tools for studying meaning.

\subsection{Distance and similarity}
\begin{itemize}[leftmargin=1.4em]
  \item \jargon{Euclidean distance}: ordinary straight-line distance,
  just in many more than two dimensions. Smaller = more similar.
  \item \jargon{Cosine similarity}: whether two points point in the
  \emph{same direction} from the origin, ignoring vector length. Ranges
  $-1$ (opposite) to $1$ (identical direction), $0$ meaning unrelated.
\end{itemize}
Both are always reported side by side, never collapsed into one number.

\subsection{Centroid}
The \jargon{centroid} of a group of points is their average position --
a stand-in for "the centre of gravity" of, say, everything the
literature corpus says, so whole-source comparisons reduce to one
number (the distance between two centroids) instead of comparing every
point pair.

\subsection{Standardization and PCA (dimensionality reduction)}
Every dimension of every vector was \jargon{standardized} before
pooling, so no single source dominates purely because its raw numbers
happen to be larger. \jargon{PCA} then compresses the 1,024-number
description of each point down to the smallest number of dimensions
that still keeps 95\% of the original variation -- 389 dimensions this
run. Every distance and similarity number below is computed in this
389-dimensional space, not the original 1,024.

\subsection{UMAP and 2-D pictures}
389 dimensions cannot be drawn on a page. \jargon{UMAP} produces a
readable (if approximate) 2-D layout purely for visualisation, trying
to preserve which points were close/far in the real space. A plain 2-D
\jargon{PCA slice} (the first two principal components) is shown
alongside for the same reason two projections of a 3-D object each show
something the other misses. Neither picture is itself evidence -- the
real numbers come from the full 389-dimensional space.

\subsection{k-nearest-neighbour composition}
A point's \jargon{k nearest neighbours} are the $k$ closest other
points ($k=10, 20$ here). Averaging their source-composition over many
points from a given source asks "how much do these sources actually
overlap, versus sitting in their own separate regions?"

\subsection{Silhouette score}
A number, roughly $-1$ to $1$, scoring how well a proposed grouping
(the three expression sources) matches the data's actual geometric
clustering. Near 0: the groups do not correspond to distinct clusters.
Near 1: they line up almost perfectly with the data's real shape.

\subsection{Bootstrap resampling and confidence intervals}
Figures reported as "mean, 95\% CI [low, high]" come from
\jargon{bootstrap resampling}: repeating a measurement many times (100
here) on randomly resampled subsets, then looking at how much the
answer varies. A narrow interval means the measurement is stable; a
wide one means it is noisier than it looks.

\subsection{"Point role" versus "source dataset"}
\jargon{source\_dataset}: which of the eight underlying datasets a
point came from. \jargon{point\_role}: a coarser grouping into
\textbf{expression} (an actual claim), \textbf{reference} (background
vocabulary, not a claim), or \textbf{emergent} (a named thing the
corpora mention). Figures are generally shown coloured both ways.

\subsection{"Equal-size-controlled" and "equal-$n$" comparisons}
The three sources are wildly different in size (5,741 / 108 / 64 this
run), and the three reference vocabularies are too (3,000 / 1,500 /
195). A raw "which is nearest, on average" comparison is biased simply
by pool size. An \jargon{equal-size-controlled} comparison down-samples
every set to the smallest before comparing. This controls for
\emph{one} bias (size) only -- not evidence the sets are otherwise
interchangeable.

\subsection{Typicality and "borderline" points (new this run)}
\label{sec:jargon_typicality}
A point's \jargon{typicality}, in this document, is nothing more than
\emph{how close it sits to its own group's centroid}. Close = "typical"
of that group's average position in the space; far = "atypical." A
\jargon{borderline} point, between two groups $A$ and $B$, is one whose
distance to $A$'s centroid and to $B$'s centroid are nearly equal --
geometrically in-between, not evidence that the underlying claim is
genuinely ambiguous or disputed in meaning. Both notions describe
\emph{this embedding space, under this model, this run} -- not
cognitive prototypicality or real-world category membership.

\section{Spot-check: is this run's data trustworthy?}
\label{sec:spotcheck}
% ============================================================

Before writing up any result from this run, a fresh random sample was
drawn from each corpus's final, judge-accepted output (100 literature,
40 MIVILUDES, 30 interview expressions; seed 42; full methodology and
config in \texttt{processed/audits/v2\_spotcheck\_20260909.md} and the
sample files themselves under each corpus's own \texttt{review/}
folder). Two things were checked: an automated pass (does every sampled
expression's text actually occur verbatim in its own recorded context;
does the judge model's own faithfulness/extraction-issue flags line up
with acceptance), and an independent read of a subset of rows by the
researcher's assistant.

\textbf{Automated pass}: 0 of 170 sampled rows failed the verbatim
check; 0 had a judge-flagged faithfulness or extraction-issue problem.
This mostly confirms the judge model's own labels are internally
consistent -- expected, since the sampled file only contains
judge-accepted rows -- rather than an independent signal on its own.

\textbf{Independent read}: literature and MIVILUDES rows read as
expected throughout -- correctly attributed claims/definitions/named
groups, sensible claim-mode and epistemic-status tags. One literature
row's expression looked, at first glance, unrelated to the printed
context; the full context window (an encyclopedia source, one entry
ending and the next beginning mid-chunk) shows the expression is
genuinely present verbatim -- a reading artefact from truncating a long
context window for a quick look, not an extraction error.

\begin{plainbox}[One genuine finding: "Sept?"]
v2's shared-space build deliberately does not filter by a minimum word
count (\texttt{--min-expression-words 0}), because a plain word count
cannot distinguish a meaningful short item ("Tomato cult!", "Illuminati",
"Gourou") from a meaningless fragment. Checking every $\leq$2-word
expression across all three corpora (1,132 literature, 7 MIVILUDES, 17
interviews) confirms this worked as intended in all but one case: 16 of
17 short interview items are genuine named entities or associations.

The exception, interview \texttt{b3-aug23-1213} (participant, age 97):
asked in French "\emph{Quand je te dis le mot secte à quoi tu
penses?}" ("When I say the word `secte' [cult], what do you think
of?"), the participant answered \textbf{"Sept?"} ("seven?") -- almost
certainly a mishearing of \emph{secte} as \emph{sept}, not a
substantive response. The judge model scored it faithful,
self-contained, cult-relevant, and atomic, correctly noting it \emph{is}
a direct quote from the transcript -- true, but the string itself
carries no propositional content about cults, so it embeds wherever
"Sept?" alone happens to land, not wherever a genuine response would.
Scale: 1 of 10,646 points (0.01\% of the whole space; 1.6\% of the
interviews corpus). Left in place, unmodified, as an explicit, logged
limitation rather than a silent unilateral exclusion -- consistent with
how the \texttt{--min-expression-words}/\texttt{--entity-anchor-min-mentions}
threshold choices elsewhere in this project were surfaced rather than
decided silently.
\end{plainbox}

\section{Honesty notes -- what these numbers do not show}
\label{sec:honesty}

Collected in one place, since they matter for how any of this gets
written up. Several are unchanged from the v1 document; new ones are
marked.

\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Corpus imbalance persists.} Literature is 97.09\% of
  all v2 expression points (v1: 97.44\%) -- essentially unchanged, and
  still requires the equal-$n$/equal-size corrections used throughout.
  \item \textbf{(New) The equal-$n$ draw shrank from 204 to 64 points.}
  The correction logic is unchanged and still necessary, but every
  bootstrapped confidence interval in this document rests on a smaller,
  noisier sample than the equivalent v1 number.
  \item \textbf{MIVILUDES is still two documents, now with only 108
  expressions surviving strict extraction.} Treat MIVILUDES's results
  as one influential operational framework's own text, read very
  closely -- not a representative sample of French state framing in
  general, and now an even smaller textual base than v1's already-small one.
  \item \textbf{The interview sample is a convenience sample, now with
  only 64 surviving expressions.} Exploratory prototype evidence, not a
  representative survey of lay usage -- and now the smallest of the
  three corpora by a wide margin.
  \item \textbf{\texttt{response\_rank} is still not usable} as a
  "first thing they thought of" signal -- only the ported
  initial-exemplar layer should be used for interview-side "first
  impression" claims.
  \item \textbf{(New) Zero entities are mentioned by all three corpora

  corpus (Section~\ref{sec:entities}), not a bug and not evidence that
  the three sources talk about nothing in common -- centroid-level and

  cross all three.
  \item \textbf{(New) One point ("Sept?") carries essentially no

  \item \textbf{Equal-size-controlled comparisons control for pool size
  only.} Still not evidence the three reference vocabularies are

  \item \textbf{2-D pictures are a reading aid, not evidence.} The real

  \item \textbf{Three language representations of the MIVILUDES

\section{Possible interpretations}
\label{sec:interpretation}
% ============================================================

\begin{plainbox}[Read this box before the rest of this section]
Everything above this point is descriptive: what was measured, and what
came out. Everything in this section is a \emph{reading} of that
description -- provisional, argued for rather than proven, and offered
because it was explicitly asked for as a first pass, not because the
geometric evidence alone settles any of it. Each interpretation below
is marked with its own tan box and paired with the specific fact it is
reading, plus at least one reason it might be wrong. None of this
should be copied into the thesis's Results chapter as a conclusion
without the researcher independently deciding it holds up.
\end{plainbox}

\begin{interpbox}[On the corpora "pointing the same direction" in v2]
Section~\ref{sec:results}'s global-structure numbers show cosine
similarities between the three corpora's centroids jumping from
near-zero/negative in v1 to solidly positive (0.26--0.64) in v2. One
reading: v1's over-inclusive extraction pulled in enough noise
(paraphrase drift, headings, off-topic bibliography text) that each
corpus's average position was itself noisy and only weakly related to
what that corpus was actually saying about cults; v2's stricter,
verified extraction may be giving a cleaner signal of real overlap in
how these three very different sources actually talk about the topic.
\textbf{Why this might be wrong}: cosine similarity between two
centroids is also mechanically sensitive to how many points went into
each average and how much they vary -- a smaller, more homogeneous
sample (v2's) can produce a tidier-looking centroid almost by
construction, regardless of whether the underlying overlap in meaning
actually grew. Distinguishing "cleaner signal" from "smaller-sample
artefact" would need something this run does not provide, e.g.\
resampling v1's own corpus down to v2's size and checking whether its
cosine similarities move the same way.
\end{interpbox}

\begin{interpbox}[On self-clustering \emph{dropping} for every source in v2]
Section~\ref{sec:cluster}'s k-NN table shows every source less
self-clustering in v2 than in v1, most sharply for interviews (85.5\%
$\to$ 69.7\%). One reading: with a much smaller equal-$n$ draw (64 vs.\
204 points), each source's own "cloud" is thinner and more easily
pierced by a handful of near neighbours from elsewhere, so \emph{some}
of this drop is close to a guaranteed side-effect of Stage~7's
shrinking sample size, not a genuine change in overlap. A second,
not-mutually-exclusive reading: if v1's extraction retained near-duplicate
paraphrases and boilerplate within each source (exactly what the
fidelity review that motivated v2 found), those duplicates would have
artificially inflated \emph{within-source} self-similarity in v1 --
so some of the drop could be v1 overstating self-clustering, not v2
understating it. \textbf{Why either might be wrong}: both silhouette
scores stay near zero regardless, so under either reading the headline
conclusion -- the three sources substantially overlap rather than
forming clean clusters -- does not change; what is genuinely uncertain
is only the size of the \emph{difference} between v1 and v2 on this
specific, sample-size-sensitive statistic.
\end{interpbox}

\begin{interpbox}[On named entities sitting at the "atypical" edge]
Section~\ref{sec:typicality} found, in all three corpora, that the most
atypical items (furthest from their own corpus centroid) are specific
named people or groups, while the most typical items are generic
cult/sect vocabulary. One reading: a corpus centroid is, in effect, an
average over a lot of generic descriptive and evaluative language, so
it should be geometrically closest to more of that same generic
language and furthest from any one idiosyncratic proper name, which by
definition carries lexical content specific to itself rather than
shared with most other expressions in the corpus. On this reading the
pattern says more about how averaging text embeddings behaves than
about which named things are "more" or "less" central to cult
discourse. \textbf{Why this might be wrong, or at least incomplete}:
if it were purely a name-versus-generic-language artefact, it should
apply equally to \emph{every} named entity regardless of how central or
fringe that entity is to the corpus's own concerns -- checking whether
frequently-discussed named groups (e.g.\ Scientology, mentioned
repeatedly across the literature) are systematically less atypical
than one-off names would help separate a pure lexical-averaging effect
from one that also tracks how much attention a given named thing
actually receives; this run's typicality module was not set up to
answer that finer question.
\end{interpbox}

\begin{interpbox}[On language-representation sensitivity getting worse in v2]
Section~\ref{sec:results}'s criterion-neighbours module found more
criteria change their "nearest corpus" answer under a different
language representation in v2 (3--4 of 17) than in v1 (0--1 of 17).
One reading: with literature down to 5,741 points and MIVILUDES down to
108, the candidate pool feeding each "nearest corpus" decision is much
smaller, so a handful of individual points shifting position under a
different embedding of the same French text is more likely to actually
flip which corpus comes out nearest -- a direct, expected consequence
of a much smaller corpus, not evidence that v2's translations are
somehow less reliable than v1's. \textbf{Why this might be wrong}: it
is also possible the specific criteria whose ranking flips are ones
sitting in a genuinely contested region of the space regardless of
corpus size, in which case the increase in flips reflects something
substantive about those particular criteria rather than sample size
alone -- Section~\ref{sec:results}'s table of which criteria flipped
would be the place to check this by re-reading which specific criteria
recur across both v1 and v2's flip lists, which this document has not
done.
\end{interpbox}
